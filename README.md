# vulnerabilidades-cisa-python
Proyecto de Recopilación de Vulnerabilidades Públicas
Descripción
Script desarrollado en Python para recopilar vulnerabilidades públicas desde fuentes oficiales de ciberseguridad como CISA y NVD.
El script obtiene información de:
CVE
Proveedor
Producto afectado
Descripción
Fecha
CVSS
Severidad
Estado de ransomware
Posteriormente genera automáticamente un archivo Excel con los resultados obtenidos.
Tecnologías utilizadas
Python
Requests
Pandas
OpenPyXL
Fuentes utilizadas
CISA Known Exploited Vulnerabilities Catalog
National Vulnerability Database (NVD)
Resultado
El script genera un archivo Excel con vulnerabilidades públicas enriquecidas con información CVSS y severidad.
